# Stylometry-Analysis-of-Human-and-Machine
This work tackles academic integrity issues—plagiarism, fabrication, and authorship verification—by proposing an NLP-based framework for authenticating student content via author attribution and style change detection. Four tasks are studied and evaluated on Gemini-generated datasets, with code and resources publicly shared for future research.
